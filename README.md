Tehtävä 2 (Numeron arvaus)

Arvaa numero:

Sovellus arpoo satunnaisen kokonaisluvun väliltä 1–100.
Käyttäjä syöttää arvauksen tekstikenttään ja painaa Make guess -painiketta.
Ohjelma tarkistaa arvauksen vertaamalla sitä satunnaislukuun ja kertoo, onko arvaus liian pieni vai liian suuri.
Jos arvaus on oikein, sovellus näyttää arvausten lukumäärän ja peli loppuu.
